#   pip install -r requirements-airflow.txt \

#
# (On Python 3.12 use constraints-3.12.txt; Airflow 2.9.3 supports 3.8-3.12.)
#
# IMPORTANT: Airflow 2.9.3's constraints pin DIFFERENT pandas/numpy versions than

# the pins here). Do NOT install this into the same environment as
# requirements.txt. Run Airflow in its own virtualenv / Docker container; the
# local one-command repro uses the plain Python runner and never needs Airflow.
